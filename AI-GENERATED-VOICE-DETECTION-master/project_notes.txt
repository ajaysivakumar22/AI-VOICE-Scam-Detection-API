# AI Voice Detection API - Project Notes
Date: February 1, 2026
Status: Production Ready (Local & Cloud Compatible)

## 📌 Project Overview
A FastAPI-based application that detects whether an audio clip is Human or AI-Generated.
- **Frontend**: Single Page Application (HTML/JS) served at `/`.
- **Backend**: FastAPI with Machine Learning inference.
- **Model**: Random Forest Classifier trained on ~830 audio samples.
- **Features**: Analyzes 49 audio features (MFCCs, Pitch, Jitter, Shimmer, Spectral Rolloff/Bandwidth/ZCR).

## 🚀 Quick Start
1. **Activate Virtual Environment**:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
2. **Run Server**:
   ```powershell
   cd ai_voice_detection_api
   python -m uvicorn app.main:app --reload --port 8000
   ```
3. **Access**:
   - Web UI: http://127.0.0.1:8000
   - API Docs: http://127.0.0.1:8000/docs

## 🛠️ Key Fixes & Implementation Details (Preserved Context)

### 1. Audio Normalization (Critical for Accuracy)
- **Issue**: The model was trained on 22050Hz audio. Uploaded files (44.1kHz, 48kHz) caused feature mismatch, leading to low confidence or wrong predictions.
- **Fix**: `app/audio/decoder.py` now **strictly forces** `sr=22050` during decoding for all formats (MP3/WAV). This matches the training pipeline exactly.

### 2. Deployment / Portable Paths
- **Issue**: `decoder.py` had a hardcoded absolute path to FFmpeg on a specific user's machine (`C:\Users\ajays\...`). This would break on Render/Cloud.
- **Fix**: The code now uses `shutil.which('ffmpeg')` to find FFmpeg dynamically. It contains a fallback check for the local Windows path *only if needed*, making it "Judge-Proof" and cloud-ready.

### 3. Confidence Score Logic
- **Issue**: Previously, the confidence score for "AI_GENERATED" was calculated incorrectly (e.g., showing 0.04 confidence for "Human" instead of 96% for "AI").
- **Fix**: `app/ml/predictor.py` now calculates confidence as the absolute distance from uncertainty (0.5), ensuring high scores (e.g., 0.98) for both clear Human and clear AI results.

### 4. Model Upgrade (V2)
- **Action**: Retrained model on Feb 1, 2026.
- **New Features**: Added Spectral Rolloff, Spectral Bandwidth, and Zero-Crossing Rate to better detect the "perfect/unnatural" frequency cutoffs of AI voices.
- **Accuracy**: Improved from ~95% to **98.2%**.

## 📂 Deployment Notes (Render/Docker)
- **FFmpeg**: The application requires FFmpeg.
  - **Docker**: Add `RUN apt-get install -y ffmpeg`
  - **Render**: Add "ffmpeg" to System Dependencies.
  - **Fallback**: The app will start even if FFmpeg is missing (logs a warning), but `pydub` decoding might fail for non-WAV files.
- **Environment Variables**:
  - `API_KEY`: Set this in the cloud environment variables. The frontend automatically injects it.

## 📝 File Structure Highlights
- `app/main.py`: Entry point, API endpoints, static file serving.
- `app/audio/features.py`: Feature extraction logic (49 features).
- `app/audio/decoder.py`: Robust audio loading (Base64 -> Bytes -> Waveform).
- `training/train_model.py`: Script to retrain the model (Run using `python training/train_model.py` from `ai_voice_detection_api` folder).
